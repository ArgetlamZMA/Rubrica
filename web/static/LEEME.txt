PDF STUDIO — versión web (sin instalar)
=======================================

Esta carpeta contiene la interfaz de Rúbrica para usar en el navegador.
Para la aplicación de Windows con instalador, firma con el almacén de
certificados y actualizaciones automáticas, descargue Rubrica-Setup-x.y.z.exe
desde https://github.com/ArgetlamZMA/Rubrica/releases

USO
1. Doble clic en «Iniciar Rubrica.bat» (abre http://localhost:8765/).
   También puede abrir index.html directamente (sin conexión a la nube).
2. Opcional: en Edge o Chrome, menú ⋯ > Aplicaciones > «Instalar Rúbrica».

Instrucciones para OneDrive/Google Drive: ⚙ Configuración dentro de la app.
