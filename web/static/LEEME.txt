PDF STUDIO — versión web (sin instalar)
=======================================

Esta carpeta contiene la interfaz de PDF Studio para usar en el navegador.
Para la aplicación de Windows con instalador, firma con el almacén de
certificados y actualizaciones automáticas, descargue PDFStudio-Setup-x.y.z.exe
desde https://github.com/ArgetlamZMA/pdf-studio/releases

USO
1. Doble clic en «Iniciar PDF Studio.bat» (abre http://localhost:8765/).
   También puede abrir index.html directamente (sin conexión a la nube).
2. Opcional: en Edge o Chrome, menú ⋯ > Aplicaciones > «Instalar PDF Studio».

Instrucciones para OneDrive/Google Drive: ⚙ Configuración dentro de la app.
